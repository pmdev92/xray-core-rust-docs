# Socks5 Outbound

The Socks protocol is a standard protocol implementation that is compatible with SOKCS5.

## OutboundConfigurationObject

```json
{
  "address": "127.0.0.1",
  "port": 4080
}
```

> **`address`**: *string*
- **Optional**: No
- **Description**: The server address.


> **`port`**: *number*
- **Optional**: No
- **Description**: The server port.
