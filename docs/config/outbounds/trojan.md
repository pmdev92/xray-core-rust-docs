# Trojan Outbound

Trojan protocol.


## OutboundConfigurationObject

```json
{
  "address": "127.0.0.1",
  "port": 4080,
  "password": "...",
}
```

> **`address`**: *string*
- **Optional**: No
- **Description**: The server address.


> **`port`**: *number*
- **Optional**: No
- **Description**: The server port.


> **`password`**: *string*
- **Optional**: No
- **Description**: The user password of trojan server.
