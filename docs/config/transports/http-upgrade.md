# HttpUpgradeObject

```json
{
  "host": "...",
  "path": "..."
}
```

### Parameters

> **`host`**: *string*
- **Optional**: Yes
- **Default value**: `""`
- **Description**: http upgrade host.

> **`path`**: *string*
- **Optional**: Yes
- **Default value**: `"/"`
- **Description**: http upgrade path.
